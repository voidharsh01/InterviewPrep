# Java Hands-On

Java practice code for interview prep, grouped by topic (all under `src/`):

| Folder | Contents |
|---|---|
| `Concurrency/` | Multithreading (semaphores, ThreadLocal, volatile, even/odd printer, thread states), Atomic, CompletableFuture |
| `Java8/` | Streams, stream practice problems, method references |
| `DesignPatterns/` | Adapter, plus State (ATM), Builder, Singleton, Composite, Command |
| `CoreJava/` | Cloneable, custom exceptions, Reflection |
